故障排查

如果代码块方式不工作：

  1. 重启 Hexo 服务器：Ctrl+C 停止，然后再运行 hexo server
  2. 清除缓存：hexo clean 然后 hexo server
  3. 确认 div 标签方式是否生效（确认 CSS 已加载）
