向量数据库
Nobody Lv2
  2026-03-05 10:00:00  
  • RAG

向量数据库是专门用来存储和检索高维向量的数据库，核心能力是近似最近邻搜索，也叫 ANN，能在百万甚至亿级的向量里快速找出最相似的几条。本地开发使用Chroma，中小规模使用Qdrant，超大规模使用Milvus。PostgreSQL支持pgvector插件。

向量数据库 基础

  • 向量数据库是什么：专门用来存储和检索「向量」的数据库。
  • 向量数据库的核心操作：近似最近邻搜索（ANN，Approximate Nearest Neighbor）。给定一个查询向量，在库里找出和它最相似的 K 个向量，返回对应的原始内容。
  • 为什么需要向量数据库：普通的关系型数据库只能根据B-Tree索引进行精准匹配，不能基于向量进行相似度排序。

索引算法

HNSW（Hierarchical Navigable Small World）

分层可导航小世界地图

  • 核心原理：构建一个多层图结构，查询时从最上层的稀疏图开始导航，快速定位大致范文，再逐层收窄范围，最终在底层找到最近邻。类似于跳表。
  • 优点：召回率高（通常能达到 95%+ 的精度）、查询速度快。
  • 缺点：建索引时内存消耗大，内存消耗和向量数量成正比，不适合内存极度受限的场景。
  • 关键参数：
    • M：「每个节点最多认识几个邻居」，M 越大，图越密，找到最近邻的精度越高，但建索引的内存和时间都越多，通常设 16～32。
    • ef_construction：「建图时每个节点考察多少候选」，越大越精确，但建索引越慢，通常设 100～200。
    • 查询参数ef（也叫 search_ef）：查询时搜索的候选集大小，越大召回越准，延迟也越高，按实际需求在 50～200 之间调。可以理解为「查询时多看几个候选再决定最终答案」，ef 小查得快但可能漏掉真正最近的那个，ef 大查得慢但结果更准。

IVF（Inverted File Index）

  • 核心原理：先对向量做聚类，把相似的向量分进同一个「桶」里，查询时只搜最相关的几个桶。
  • 优点：内存占用小、适合超大规模。
  • 缺点：精度比 HNSW 略低，需要调参（聚类数量 nlist、搜索桶数量 nprobe）。

向量数据库的核心能力

  • Metadata 过滤
    • Metadata 过滤，也叫混合检索，支持给每个向量挂载 metadata字段。
    • 前置过滤：向量数据库支持给每个向量挂上 metadata 字段，检索时加过滤条件，只在符合条件的子集里做 ANN 搜索。
  • 实时更新：主流的向量数据库都支持在线写入，新数据进来后增量构建索引，不需要停服重建。
  • 关键词检索融合：纯向量检索对一些精确词语的效果不好，部分向量库同时支持向量检索 + BM25 关键词检索，做混合召回效果更好。

Milvus

核心概念

  • Collection（集合）：类似关系数据库里的「表」，存储一类向量数据。一个知识库对应一个 Collection，每条记录包含：文本 chunk 的 ID、向量（embedding）、原文内容、来源文档等 metadata。
  • Segment（段）：Milvus 内部管理数据的基本单位。新写入的数据先进「增量段」，像一个临时的接收缓冲区；积累到一定量后触发合并，变成「封存段」。封存段会建好索引，查询时走索引检索速度很快。
    • 新数据直接写入「增量段」，无需立即简历索引。
    • 后台自动合并小段，优化存储和查询策略。
    • 合并这个动作本身会消耗 CPU 和磁盘，就像磁盘碎片整理，把一堆小文件合并成大文件，期间会抢资源。
  • Index（索引）：向量检索的关键加速结构。

性能优化

  • 内存不足，频繁swap，查询延迟飙升：
    • 开启 标量量化（SQ8） 之后，把每个 float32 压缩成 int8（用 1 字节代替 4 字节）。精度损失不到1%，数据量缩减到25%。
  • 批量写入触发 Segment 合并，查询抖动：
    • 一次性写入几十万条新数据时，Milvus 后台会触发 Segment 合并操作，把多个小的增量 Segment 合并成大的封存 Segment 并建好索引，耗费CPU和磁盘开销，期间查询的 P99 延迟会有明显抖动。
    • 时间上错峰，把批量写入改到业务低峰期（比如凌晨），避开查询高峰，让 Segment 合并在用户不活跃时静默完成。
    • 化整为零，把每批写入量控制在 500～1000 条以内，分成多批写，每批之间间隔几秒。这样 Segment 合并的冲击变成多次小冲击，而不是一次大冲击，每次合并规模小、耗时短，查询服务基本感知不到抖动。
