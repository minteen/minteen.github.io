Embedding 概念

  • 语义压缩，把一段自然语言文本映射成一个固定长度的浮点数向量。
  • 语义相似：语义相近的文本，向量的余弦相似度高。

如何选择合适的 Embedding 模型

判断依据：

  1. 中英文比例：知识库以中文为主，选 bge-large-zh；中英混合，选 bge-m3；纯英文或追求省事，选 text-embedding-3-small。
  2. 向量维度：维度越高精度越好，但存储成本也越大。
  3. 领域微调。

评估

Hit@K指标：正确的 chunk 出现在前K条结果的比率

Embedding 算法

  1. 静态词向量：以 Word2Vec 为代表，把每个词映射成固定向量，但同一个词不管上下文是什么，向量永远不变，处理不了多义词。
  2. 上下文相关向量：以 BERT 为代表，同一个词在不同语境下有不同的向量，表达能力大幅提升。
  3. 以 SBERT、SimCSE、BGE 为代表的句子级对比学习 Embedding，专门为「两段文本有多相似」这个任务优化，能提前把所有文档向量算好存起来，查询时只需算一次，是 RAG 场景的标配。

静态词向量

  • 代表：Word2Vec，GloVe，FastText
  • 核心思路：用一个词周围的词来预测这个词，或者反过来用这个词来预测周围的词。

上下文相关向量

  • ELMo：用双向 LSTM 来建模，同时从左往右和从右往左扫描句子，把两个方向的隐藏状态拼起来作为词的上下文向量。
  • BERT：用 Transformer 替代 LSTM，引入了 Masked Language Model 预训练任务，效果全面超越 ELMo，成为 NLP 领域最重要的里程碑之一。BERT 用 [CLS] token 来表示整个句子，同时看到前后文（双向），表达能力远超单向模型。
  • BERT的缺陷：如果要比较两个句子的相似性，必须将两个句子拼接在一起给BERT。在RAG场景下，需要对查询和所有的候选chunk进行计算。

句子级对比学习

  • SBERT：用 bi-encoder 结构：两个句子分别独立过 BERT，各自得到一个句子级向量，然后只用余弦相似度来衡量两个向量的距离。
  • SimCSE：使用对比学习，把同一句话做两次 dropout 得到两个不同的向量，把这两个向量作为正样本对，让模型学会把它们拉近；同时把同一个 batch 里其他句子的向量作为负样本。
    • 不需要人工标注。
    • BERT 原生的句子向量存在「各向异性」，也就是说向量分布是扭曲的，都挤在一个窄小的锥形区域里，没有充分利用向量空间。SimCSE 通过对比学习把向量「撑开」了，让语义空间变得更均匀。
  • BGE：基于对比学习在大规模中英文数据上训练，同时支持 bi-encoder 和 reranker 两种形态，专门为检索场景优化。
世代 代表模型 核心特点 主要局限 RAG 适用性
第一代 Word2Vec、GloVe、FastText 词级静态向量 无法处理多义词，词级非句子级 不适用
第二代 ELMo、BERT 上下文动态向量 检索时需两两拼接，速度极慢 不适用于实时检索
第三代 SBERT、SimCSE、BGE、E5 句子级 bi-encoder，对比学习 精度低于 cross-encoder 标配，性能和精度平衡最优
